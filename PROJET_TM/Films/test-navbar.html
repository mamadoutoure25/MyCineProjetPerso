Test de la Navbar

Cette page teste la navbar pour les thèmes sombre et clair. Cliquez sur le bouton de thème (soleil/lune) en haut à droite pour basculer entre les deux modes.

Instructions

  • Cliquez sur le bouton de thème en haut à droite
  • La navbar devrait changer de couleur
  • Les textes doivent rester lisibles dans les deux thèmes
  • Le thème doit persister lors du rechargement
  • Les transitions doivent être fluides

Points de Vérification

✓ Logo visible

Le logo "M" est visible et bien positionné

✓ Brand lisible

Le texte "MyCiné" est lisible avec bon contraste

✓ Liens visibles

Les liens de navigation sont visibles et au survol deviennent rouges

✓ Bouton thème

Le bouton de thème a une bonne visibilité et interaction

✓ Transitions

Les changements de thème sont fluides et sans scintillement

✓ Persistance

Le choix du thème est sauvegardé dans localStorage
