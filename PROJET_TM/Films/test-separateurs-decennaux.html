Séparateurs Décennaux

Le dropdown des années affiche maintenant des séparateurs visuels tous les 10 ans pour faciliter la navigation!

🧪 Instructions de Test

  1. Cliquez sur le dropdown "Années" dans la navbar en haut
  2. Vous verrez:
    • ✅ Les années futures et récentes (2028 à 2014)
    • ✅ Un séparateur principal (ligne épaisse)
    • ✅ Les années anciennes avec des séparateurs tous les 10 ans
  3. Scrollez dans le dropdown pour voir les séparateurs décennaux
  4. Chaque séparateur marque une nouvelle décennie (2010s, 2000s, 1990s, etc.)
  5. Testez le changement de thème (clair/sombre)
